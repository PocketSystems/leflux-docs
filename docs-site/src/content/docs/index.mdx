## What is LeFlux?

LeFlux is a JavaScript widget you add to your website. Visitors chat in natural language. The agent can answer from your site's public pages, help them navigate, and assist with supported forms. When a visitor needs a person, your team can take over the conversation.

After you add your site in the dashboard, install one `<script>` tag. LeFlux works with plain HTML, React, Next.js, WordPress, Shopify, Webflow, Framer, and other sites that allow custom scripts.

## Add the widget with one script

```html
<script src="https://leflux.ai/embed.js" async></script>
```

The script does not need a token or API key in the page. First, add your site and allowed host in the dashboard; then paste the script. The widget loads your site's settings and mounts inside a shadow DOM to avoid common CSS conflicts.
